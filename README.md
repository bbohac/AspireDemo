# Aspire Demo

This repository serves as a playground for exploring and demonstrating the capabilities of **.NET Aspire**.  
For more information about .NET Aspire, visit the official documentation:  
https://learn.microsoft.com/en-us/dotnet/aspire/

## Goals

The initial goal of this project is to host a **.NET API backend** that provides data to a **React frontend**.  
This setup allows experimenting with distributed application development using Aspire’s orchestration and monitoring features.

## Roadmap

Additional goals planned for future iterations include:

- Persisting data in a **PostgreSQL database** hosted in Docker
- Introducing **caching** to improve performance
- Adding **observability features** (metrics, logs, tracing) using Aspire’s built‑in tooling
- Implementing **message-based communication** (e.g., Azure Service Bus or RabbitMQ)
- Securing the application using **authentication & authorization**
- Deployment to **Microsoft Azure**, potentially using GitHub Actions or other CI/CD pipelines

This list will grow as the project evolves and new Aspire features are explored.
